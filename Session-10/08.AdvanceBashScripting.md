# Advance Bash Scripting
- 1. Background Process
    - to run bash script in Background just add '&' after the script name
```
text.sh &
sleep 60
```
    - This will keep the thread in the background along with that it will create JOB ID amd PID
OUTPUT:
```
[2] 13911
```
- here '2' is the JOB ID and '13911' is PID 

## Open the 'Jobs' using WSL
```
jobs
```
## to get the process in Foreground
```
fg %1
```
- [Note: Here 1 is the job id]
