# Advance Bash Scripting
- 1. Background Process
    - to run bash script in Background just add '&' after the script name
```
text.sh &
sleep 60
```
    - This will keep the thread in the background along with that it will create JOB ID amd PID
OUTPUT:
```
[2] 13911
```
- here '2' is the JOB ID and '13911' is PID 

## Open the 'Jobs' using WSL
```
jobs
```
## to get the process in Foreground
```
fg %1
```
- [Note: Here 1 is the job id]

# Kill The Process and JOB ID
- 1. to kill the process
```
kill <PID> 
or
kill 12345
or 
kill -9 <PID>
```
- 2. To Terminate the JOB ID
```
kill %1
```
- here %1 is JOB ID
# Running a Process in the Background and Keeping it alive
- nohup - No Hang Up
- when we close the terminal process terminated by default, To Prevent This
```
nohup ./script.sh &
```
- output is saved in nohup.out by default
```
./script.sh &
disown
```
- this will remove the process from the job table, so it won't be terinated when the session ends
