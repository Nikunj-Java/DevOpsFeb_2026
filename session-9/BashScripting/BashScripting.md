# Bash Scriptinh
BASH= Bourne Again SHell
- it is command line interpreter and scripting langugae commonly used in UNIX- Based System like Linux and Mac OS
- it allows users to sutomate the tasks, Manage System Operation, and write Scripts for Repetative Task

## What is SHEBANG 
```
#! /bin/bash
```
## Step by Step Exmplanation
- step:1 Create a FILE
```
nano hello.sh
```

- Step:2 Create Code and Execute
```
#! /bin/bash
echo "Hello World!"
```

- Step:3 Make the Script Executable
```
chmod +x hello.sh
```
[Note: hello.sh will be the name of your file with extension]

- Step:4 Run the Script
```
./hello.sh
```
## Output:
```
./hello.sh
```
