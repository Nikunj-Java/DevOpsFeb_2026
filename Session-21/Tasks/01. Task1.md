# Jenkins Python CI/CD Tasks with Solutions

# Task 1: Create a Simple Jenkins Pipeline for Python Calculator App

## Objective

Create a Jenkins pipeline that:

* Clones Python project from GitHub
* Installs dependencies
* Runs Python application

---

## Project Structure

```text
Python_ci_2026/
│
├── calculator.py
├── requirements.txt
└── Jenkinsfile
```

---

## calculator.py

```python
print("Python Calculator Application Running Successfully")
```

---

## requirements.txt

```text
pytest
```

---

## Jenkinsfile Solution

```groovy
pipeline {
    agent any

    stages {

        stage('Clone Repository') {
            steps {
                git branch: 'main',
                url: 'https://github.com/Nikunj-Java/Python_ci_2026.git'
            }
        }

        stage('Create Virtual Environment') {
            steps {
                sh 'python3 -m venv venv'
            }
        }

        stage('Install Dependencies') {
            steps {
                sh '''
                . venv/bin/activate
                pip install -r requirements.txt
                '''
            }
        }

        stage('Run Python Application') {
            steps {
                sh '''
                . venv/bin/activate
                python3 calculator.py
                '''
            }
        }
    }
}
```

---

## Expected Output

```text
Python Calculator Application Running Successfully
```

# Task 3: Jenkins Pipeline with Email Notification

## Objective

Create Jenkins pipeline that:

* Runs pytest
* Sends email after build success/failure

---

## Required Jenkins Plugins

Install:

* Email Extension Plugin
* Mailer Plugin

---

## Configure Gmail SMTP

```text
SMTP Server: smtp.gmail.com
SMTP Port: 465
Use SSL: YES
```

Use Gmail App Password.

---

## Jenkinsfile Solution

```groovy
pipeline {
    agent any

    environment {
        EMAIL_TO = 'yourgmail@gmail.com'
    }

    stages {

        stage('Clone Repository') {
            steps {
                git branch: 'main',
                url: 'https://github.com/Nikunj-Java/Python_ci_2026.git'
            }
        }

        stage('Create Virtual Environment') {
            steps {
                sh 'python3 -m venv venv'
            }
        }

        stage('Install Dependencies') {
            steps {
                sh '''
                . venv/bin/activate
                pip install -r requirements.txt
                '''
            }
        }

        stage('Run Test Cases') {
            steps {
                sh '''
                . venv/bin/activate
                pytest
                '''
            }
        }
    }

    post {

        success {
            emailext (
                subject: "SUCCESS: Jenkins Build #${BUILD_NUMBER}",
                body: """
                Build Successful

                Project: ${JOB_NAME}
                Build Number: ${BUILD_NUMBER}

                Build URL:
                ${BUILD_URL}
                """,
                to: "${EMAIL_TO}"
            )
        }

        failure {
            emailext (
                subject: "FAILED: Jenkins Build #${BUILD_NUMBER}",
                body: """
                Build Failed

                Project: ${JOB_NAME}
                Build Number: ${BUILD_NUMBER}

                Build URL:
                ${BUILD_URL}
                """,
                to: "${EMAIL_TO}"
            )
        }
    }
}
```

---

## Expected Output

```text
SUCCESS: Jenkins Build #5
```

or

```text
FAILED: Jenkins Build #5
```

# Task 4: Jenkins Freestyle Project using Poll SCM

## Objective

Create a Jenkins Freestyle Project that:

* Automatically checks GitHub repository for code changes
* Pulls latest code using Poll SCM
* Runs Python application automatically

---

## Step 1: Create Freestyle Project

```text
Jenkins Dashboard
    ↓
New Item
    ↓
Freestyle Project
```

Project Name:

```text
Python-PollSCM-Project
```

---

## Step 2: Configure GitHub Repository

Under:

```text
Source Code Management
```

Select:

```text
Git
```

Repository URL:

```text
https://github.com/Nikunj-Java/Python_ci_2026.git
```

Branch:

```text
*/main
```

---

## Step 3: Configure Poll SCM

Under:

```text
Build Triggers
```

Enable:

```text
Poll SCM
```

Schedule:

```text
* * * * *
```

Meaning:

```text
Check GitHub repository every 1 minute
```

---

## Step 4: Add Build Step

Under:

```text
Build
```

Select:

```text
Execute Shell
```

Add:

```bash
python3 -m venv venv
. venv/bin/activate
pip install -r requirements.txt
python3 calculator.py
```

---

## Expected Output

```text
Started by an SCM change
Python Calculator Application Running Successfully
```
